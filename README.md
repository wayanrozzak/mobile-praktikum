# Aplikasi Pemesanan Makanan

## Tentang Proyek

Aplikasi Pemesanan Makanan merupakan aplikasi mobile sederhana yang dibuat menggunakan Flutter. Aplikasi ini dirancang untuk membantu pengguna melihat daftar makanan dan melakukan pemesanan dengan lebih mudah.

## Tujuan

Tujuan dari proyek ini adalah mempelajari pembuatan aplikasi mobile menggunakan Flutter sekaligus menerapkan konsep antarmuka, navigasi, dan pengelolaan data sederhana.

## Rencana Fitur

1. **Daftar Menu**
   Menampilkan berbagai makanan dan minuman yang tersedia beserta nama, harga, dan informasi singkat.

2. **Keranjang Pesanan**
   Pengguna dapat memilih makanan dan memasukkannya ke dalam keranjang sebelum melakukan pemesanan.

3. **Pemesanan**
   Pengguna dapat melihat detail pesanan dan jumlah pembayaran sebelum menyelesaikan pemesanan.

## Cara Menjalankan

Pastikan Flutter sudah terpasang dan perangkat atau emulator sudah tersedia.

Jalankan perintah berikut pada terminal:

```bash
flutter pub get
flutter run
```
